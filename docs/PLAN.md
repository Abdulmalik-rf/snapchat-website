# خطة بناء الموقع — Snapchat Verification Readiness

موقع صفحة واحدة (One Page) عربي، Mobile-First، بهوية مستوحاة من Snapchat، يبيع ثلاث باقات
لتحليل جاهزية حساب Snapchat للتوثيق. الدفع يتم عبر متجر **سلة**، والموقع يملك "محرّك" صغير:
نموذج الطلب → حفظ البيانات → التحويل إلى سلة → استقبال Webhook من سلة بعد الشراء → إرسال بريد
"شكرًا لشرائك، سنتواصل معك خلال 24 ساعة".

## التقنيات

| الطبقة | الاختيار | السبب |
| --- | --- | --- |
| إطار العمل | Next.js 16 (App Router) + TypeScript | SSR = HTML خام قابل للقراءة (العنصر 12)، مسارات API للمحرّك، نشر بضغطة على Vercel |
| التنسيق | Tailwind CSS v4 | خصائص منطقية (RTL) جاهزة، Design tokens في ملف واحد |
| الحركة | `motion` (Framer Motion) | Reveal on scroll، Stagger، عناصر 3D خفيفة (Tilt) |
| الخط | IBM Plex Sans Arabic (self-hosted عبر `next/font`) | حديث ونظيف وبدون CLS |
| التحقق | zod | نفس المخطط في المتصفح والخادم |
| البريد | Resend | API بسيط، يعمل من Serverless |
| التخزين | Upstash Redis (اختياري) | REST بدون اتصالات، مجاني، Fallback في الذاكرة أثناء التطوير |
| الدفع | سلة (منتج لكل باقة) | Webhook `order.created` / `order.status.updated` |

## المراحل

### المرحلة 1 — الأساس
- إعداد المشروع، الخط العربي، RTL، الألوان (أسود فاخر + أصفر Snapchat + أبيض).
- ملف محتوى واحد `src/content/site.ts` يحوي كل النصوص والأسعار والروابط ليعدّلها العميل بسهولة.
- شريط تنقّل زجاجي، فوتر، مكوّنات مشتركة (زر، حاوية، Reveal، Tilt).
- خلفية الفيديو `ScrollVideo`: وضع `scrub` (يتقدّم الفيديو مع التمرير) أو `autoplay`، مع خلفية بديلة
  متحركة حتى يصل فيديو العميل.

### المرحلة 2 — أقسام الصفحة
Hero → صندوق الإجابة → المشكلة/الحل → كيف تعمل الخدمة (5 خطوات) → الباقات → ماذا ستحصل عليه →
الخبير → الإثبات → جدول المقارنة → الأسئلة الشائعة → CTA أخير → فوتر.

### المرحلة 3 — محرّك الطلب
- الضغط على باقة يفتح نموذجًا (Bottom sheet على الجوال، Dialog على الشاشات الكبيرة).
- الحقول: الاسم الكامل، البريد، اسم مستخدم Snapchat، الباقة، هل سبق التقديم؟ (+ ملاحظة).
- `POST /api/lead`: تحقق zod، Honeypot، حد للطلبات، حفظ في Upstash (أو الذاكرة)، بريد للإدارة،
  ثم يعيد رابط منتج سلة الخاص بالباقة → المتصفح يحوّل العميل للدفع.

### المرحلة 4 — بعد الشراء
- `POST /api/webhooks/salla`: تحقق التوقيع (HMAC-SHA256 في `X-Salla-Signature`) أو Token،
  تجاهل الطلبات غير المدفوعة/الملغاة، منع التكرار برقم الطلب.
- بريد للمشتري: "شكرًا لشرائك — سنتواصل خلال 24 ساعة" + رقم الطلب، وبريد للإدارة مع بيانات
  النموذج المطابقة (بالبريد الإلكتروني).
- صفحة `/success?order=XXXX` بنفس الرسالة (رابطها داخل البريد، ويمكن ضبطها كصفحة شكر في سلة).
- WhatsApp: Hook اختياري عبر WhatsApp Cloud API يعمل فقط عند ضبط المتغيرات.

### المرحلة 5 — الجودة والتسليم
- Lint + Typecheck + Build، لقطات شاشة للجوال والحاسوب.
- README، دليل إعداد سلة، دليل تجهيز الفيديو (ffmpeg)، `.env.example`.

## ما يحتاجه العميل لاحقًا
1. فيديو الخلفية (MP4 + WebM) — انظر `docs/VIDEO.md`.
2. روابط المنتجات الثلاثة في سلة + سر الـ Webhook — انظر `docs/SALLA-SETUP.md`.
3. بيانات الخبير (الاسم، الصورة، الخبرة) وقصص نجاح حقيقية بأرقام.
4. مفتاح Resend ونطاق مُتحقق للبريد، ورقم WhatsApp.
